Before you use the tools

These notes apply to the Tester and Emulator only. The specifications are ordinary web pages — read them in any browser, no setup needed.

  • Chrome or Edge is required. The tools use the Web Serial API, which Safari and Firefox do not support.
  • Your data stays on your machine. The tools communicate only between your browser and the WHILL over the serial port. Nothing is sent to any server.
  • They work offline. Each tool is a single self-contained HTML file — download it and open it from a local disk on an isolated network.
